# HIDPilot 配置协议 v1

本文定义 HIDPilot 固件 `1.0.0` 的当前 wire schema。所有多字节整数均为小端，无符号字段除非另有说明。

## HID 传输

配置通道是独立 HID 顶层集合 `Usage Page 0xFF00 / Usage 0x01`，包含各 64 字节的 Input 和 Output Report，不使用 Report ID。主机每发送一个请求 Output Report，设备返回一个 Input Report；同一连接上请求必须串行发送。

键盘与鼠标位于另一个 HID 接口，不属于本协议，也不会暴露给 WebHID 页面。

## 帧格式

| 偏移 | 长度 | 请求 | 响应 |
|---:|---:|---|---|
| `0` | 2 | ASCII `HP` | ASCII `HP` |
| `2` | 1 | 协议版本 `1` | 协议版本 `1` |
| `3` | 1 | 命令 | 请求命令按位或 `0x80` |
| `4` | 2 | 事务 ID | 回显事务 ID |
| `6` | 1 | 有效载荷长度 `0–56` | 有效载荷长度 `0–56` |
| `7` | 1 | 必须为零 | 状态码 |
| `8` | 56 | 有效载荷后补零 | 有效载荷后补零 |

事务 ID 由主机选择。普通命令可使用新的 ID；一次暂存事务的 `BEGIN`、所有 `CHUNK`、`VALIDATE` 及最终 `RUN/APPLY` 必须使用同一 ID。

## 命令

| 值 | 名称 | 请求载荷 | 成功响应载荷 |
|---:|---|---|---|
| `0x01` | `GET_STATUS` | 空 | 30 字节状态 |
| `0x02` | `GET_CONFIG_INFO` | 空 | 长度、CRC、代际 |
| `0x03` | `GET_CONFIG_CHUNK` | 偏移 `u16`、长度 `u8` | 偏移 `u16`、数据 |
| `0x10` | `STAGE_BEGIN` | 总长度 `u16`、CRC-32 `u32` | 空 |
| `0x11` | `STAGE_CHUNK` | 偏移 `u16`、数据 `1–54` 字节 | 空 |
| `0x12` | `STAGE_VALIDATE` | 空 | 空 |
| `0x13` | `RUN_ONCE` | 空 | 空 |
| `0x14` | `APPLY_TEMP` | 空 | 空 |
| `0x15` | `APPLY_SAVE` | 空 | 空 |
| `0x16` | `RESTORE_DEFAULT` | 空 | 空 |
| `0x17` | `REBOOT_APPLICATION` | 空 | 空，响应发送后重启 |
| `0x18` | `REBOOT_BOOTSEL` | 空 | 空，响应发送后进入 BOOTSEL |

`STAGE_CHUNK` 可乱序发送。完全相同的重复字节可重试；若重复范围与已接收内容冲突，返回偏移错误。`STAGE_VALIDATE` 只在每个字节均已接收、CRC 匹配且配置语义有效时成功。未验证的暂存数据不能试运行、应用或保存。

`RUN_ONCE` 不修改活动配置；执行完成后恢复活动周期调度。`APPLY_TEMP` 替换 RAM 中的活动配置并立即重新调度，但不写 Flash。`APPLY_SAVE` 先写入非活动槽并回读验证，成功后才替换活动配置。`RESTORE_DEFAULT` 恢复默认配置并保存到 Flash。

### `GET_STATUS` 响应

响应有效载荷相对偏移如下：

| 偏移 | 长度 | 含义 |
|---:|---:|---|
| `0` | 3 | 固件 major、minor、patch |
| `3` | 1 | 配置 schema 版本 |
| `4` | 1 | 位 0 启用、位 1 已挂载、位 2 挂起、位 3 执行中 |
| `5` | 1 | 当前动作索引 |
| `6` | 1 | 活动动作数量 |
| `7` | 1 | `0` 无有效槽、`1` 槽 0、`2` 槽 1 |
| `8` | 4 | 周期 ms |
| `12` | 4 | 已完成轮次计数 |
| `16` | 4 | 执行器错误计数 |
| `20` | 4 | Flash 代际 |
| `24` | 4 | 活动配置 CRC-32 |
| `28` | 2 | 活动配置字节长度 |

### `GET_CONFIG_INFO` 响应

载荷依次为配置长度 `u16`、CRC-32 `u32`、Flash 代际 `u32`。读取分块长度必须为 `1–54`，且请求范围必须完全位于当前配置内。

## 配置 schema v1

配置长度为 `12 + action_count × 8`，最大 268 字节。

### 头部

| 偏移 | 长度 | 含义 |
|---:|---:|---|
| `0` | 1 | schema 版本 `1` |
| `1` | 1 | 位 0 为启用标志，其余位必须为零 |
| `2` | 1 | 动作数量 `0–32` |
| `3` | 1 | 保留，必须为零 |
| `4` | 4 | `repeat_interval_ms`，范围 `1–86400000` |
| `8` | 4 | 保留，必须为零 |

周期是相邻两轮开始时间的最小间隔。若一轮执行时间超过周期，固件完成当前轮并释放全部输入后立即开始下一轮。零动作配置有效，每轮只更新完成计数。

### 动作记录

每个动作固定 8 字节。

| 类型 | 值 | 字节 `1..7` |
|---|---:|---|
| 延时 | `1` | `1..3=0`，`4..7 duration_ms u32`，范围 `1–60000` |
| 相对鼠标 | `2` | `x i8`、`y i8`、`wheel i8`、`pan i8`、`5..7=0` |
| 鼠标点击 | `3` | `buttons u8`、`hold_ms u16`、`4..7=0` |
| 键盘点击 | `4` | `modifiers u8`、`usage u8`、`3=0`、`hold_ms u16`、`6..7=0` |

鼠标按钮掩码允许 `1–31`，按住时间允许 `10–1000 ms`。键盘 Usage 必须为 `1–255`，修饰键是标准 HID 键盘修饰位掩码，按住时间允许 `10–1000 ms`。点击和键盘动作在按住时间结束后自动发送释放报告。

默认配置启用，周期 `55000 ms`，动作依次为相对移动 `(100, 0, 0, 0)`、延时 `200 ms`、相对移动 `(-100, 0, 0, 0)`。

配置 CRC 使用 CRC-32/ISO-HDLC：多项式反射形式 `0xEDB88320`、初值 `0xFFFFFFFF`、最终异或 `0xFFFFFFFF`；`123456789` 的校验值为 `0xCBF43926`。

## 状态码

| 值 | 名称 | 含义 |
|---:|---|---|
| `0` | `OK` | 成功 |
| `1` | `MAGIC` | 魔数不是 `HP` |
| `2` | `VERSION` | 不支持的协议版本 |
| `3` | `LENGTH` | 帧、载荷或配置长度错误 |
| `4` | `COMMAND` | 未知命令 |
| `5` | `TRANSACTION` | 暂存事务不存在或 ID 不匹配 |
| `6` | `OFFSET` | 分块越界或重复内容冲突 |
| `7` | `CRC` | 暂存配置 CRC 不匹配 |
| `8` | `CONFIG` | schema、保留字段或动作值无效 |
| `9` | `BUSY` | 另一次单次试运行仍在执行 |
| `10` | `FLASH` | 擦写、安全执行或回读验证失败 |
| `11` | `INCOMPLETE` | 暂存数据未收齐或尚未验证 |

## Flash 记录

每槽 4096 字节。记录头为魔数 `HPS1`（4 字节）、schema `u16`、配置长度 `u16`、代际 `u32`、配置 CRC-32 `u32`，随后是配置字节，其余保持 `0xFF`。

启动时独立校验两槽，使用带 32 位回绕比较的最新有效代际；若一槽损坏则使用另一槽，两槽均无效则加载默认配置。保存时只擦写非活动槽，通过 `flash_safe_execute()` 执行，完整回读成功后才切换活动槽，因此擦写期间掉电不会破坏上一有效记录。
